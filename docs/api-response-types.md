# API 응답 타입 기준

`src/types/api`의 응답 타입은 HTTP로 제공하는 필드를 명시한다. Prisma 모델을 바꿔도 API 응답 계약이 자동으로 늘어나지 않는다. 요청 타입도 이 디렉터리에서 관리한다.

`src/lib/serializers/responses.ts`는 Prisma 조회 결과에서 계약에 포함된 필드만 골라 응답으로 변환한다. 카테고리와 태그의 서버 렌더링 데이터도 같은 필드 선택을 거친다. 게시글은 서버 렌더링에서 `Date`를 유지하는 `PostView`를 사용하고, JSON 응답에서는 날짜를 ISO 문자열로 변환한다.

예를 들어 새로운 DB 필드를 추가할 때 API에 노출하려면 응답 타입과 변환 함수, 관련 테스트를 함께 수정한다. 반대로 화면에서 응답 일부만 필요하면 `Pick` 등으로 응답 타입에서 필요한 부분을 파생할 수 있다.

현재 게시글 목록과 상세·생성 응답의 작성자 필드는 기존 동작을 유지한다. 상세·생성 응답의 `emailVerified`를 포함해 공개 범위 자체가 적절한지는 별도로 검토해야 한다. 태그 상세는 공개 게시글만 조회하는 기존 정책을 유지한다.

타입 선언은 외부에서 들어오는 요청이나 응답 JSON을 런타임에 검증하지 않는다. 입력 검증 도구 도입은 별도 작업으로 남겨둔다.
